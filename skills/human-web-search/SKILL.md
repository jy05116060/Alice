# 拟人化网页搜索

在所有可控制的爱丽丝浏览器界面中，检索网页时按正常用户操作搜索页面；小卡片与大窗口共享同一页面和规则。

## 默认流程

1. 已知目标的完整官网或具体页面 URL 时，可以直接打开该 URL；这不是搜索。
2. 需要发现、比较或核实网页信息时，优先调用 `browser_navigate` 打开 `https://www.baidu.com` 首页。不得把关键词拼进 URL，也不得直接打开百度、必应、谷歌或其他搜索引擎的结果页 URL。
3. 从导航结果的最新 accessibility snapshot 中确认搜索输入框和“百度一下”按钮的当前 target。
4. 用 `browser_type` 在搜索框输入用户的完整查询；不要只截取一个关键词。
5. 用 `browser_click` 点击“百度一下”或当前页面对应的搜索按钮。仅在按钮不可用且用户没有要求点击按钮时，才可以改用 `browser_press_key` 提交。
6. 依据点击后的最新 snapshot 审阅结果，再用 `browser_click` 打开相关结果并核实信息。

## 搜索引擎与失败处理

- 用户明确指定其他搜索引擎或站内搜索时，打开该服务的首页或站内搜索入口，再执行“输入框 → 点击搜索按钮”的同一流程；不要构造关键词结果 URL。
- 百度加载失败、出现验证码或挑战页时，保留当前页面并如实说明。不要改用直链查询 URL、换搜索提供方或尝试绕过验证。
- 电脑的系统浏览器只能由 `system_browser_open` 打开，爱丽丝无法继续输入或点击；不要声称已经在该浏览器完成搜索。
- 不使用 shell HTTP 客户端、`web_search` 或其他绕过真实浏览器交互的联网方式。

最终回复只给出与问题相关且已核实的结果，不逐条复述内部点击过程。
